# Data

All data in this repository is **synthetic**. No real customer information is used.

## Schema

| Column | Type | Allowed values | Used for |
|---|---|---|---|
| `Customer_ID` | string | unique | tracking selections |
| `Actual_Churn` | int | 0 or 1 | retrospective evaluation only. Never used to choose customers. |
| `Predicted_Churn_Probability` | float | 0–1 | risk signal (stands in for a churn-model score) |
| `Estimated_CLV` | number (€) | > 0 | value potentially preserved |
| `Retention_Offer_Cost` | int (€) | > 0, whole euros | budget consumed by an offer |

Whole-euro costs are required because the dynamic-programming solver indexes the budget in €1 steps.

## Files

### `raw/project_odin_customers.csv`: reference dataset (30 rows)

Hand-built fictional customers used throughout the notebook and as the regression baseline in the tests.

| Statistic | Churn probability | CLV (€) | Offer cost (€) |
|---|---:|---:|---:|
| mean | 0.55 | 996 | 100 |
| min | 0.14 | 229 | 40 |
| max | 0.88 | 1,745 | 148 |

There are 15 actual churners and 15 non-churners. The correlation between the risk score and actual churn is 0.79.

### `synthetic/odin_customers_1000.csv`: scale dataset (1,000 rows)

Generated by `odin.synthetic.generate_customers(n=1000, seed=2024)`. Regenerate it with:

```bash
python -m odin generate --n 1000 --seed 2024 --out data/synthetic/odin_customers_1000.csv
```

Generating process:

| Field | Distribution |
|---|---|
| `Predicted_Churn_Probability` | Beta(2.2, 1.8), rounded to 0.01 and clipped to [0.01, 0.99] |
| `Estimated_CLV` | LogNormal with median €950 and σ = 0.45, clipped to [€200, €4,000] |
| `Retention_Offer_Cost` | 6% of CLV + Normal(0, €25) noise, clipped to [€30, €250] and rounded |
| `Actual_Churn` | Bernoulli(`Predicted_Churn_Probability`) |

Because `Actual_Churn` is drawn from the score itself, the risk scores in this dataset are **perfectly calibrated by construction**. Real model scores would not be. Keep this in mind when you interpret retrospective churn capture on this dataset.
